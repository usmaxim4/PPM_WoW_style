# Светогорский ЦБК: путь от леса до листа

Интерактивная страница о производстве Светогорского целлюлозно-бумажного комбината (Ленинградская область) по публичным данным. Десять карточек показывают этапы от заготовки древесины до отгрузки бумаги. По клику на карточку открывается окно с подробностями: что известно именно о Светогорске и как устроен этап в отрасли. Есть паспорт комбината, хронология (в том числе период владения Tetra Laval) и список источников с перечнем расхождений между ними.

Страница статична: один файл `index.html`, без JavaScript и без сборки. Окна работают на чистом CSS, картинки встроены в файл. Единственный внешний ресурс — шрифт Cinzel с Google Fonts; без сети подставится системный шрифт.

## Как открыть

Скачайте `index.html` и откройте в браузере двойным щелчком.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub (публичный).
2. Загрузите файлы `index.html`, `README.md` и `.nojekyll` в корень репозитория.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две страница появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | страница целиком (разметка, стили, изображения WebP в base64) |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Точность данных

Все сведения взяты из открытых источников, список ссылок приведён внизу страницы. Часть цифр опубликована самой компанией или в рекламных материалах и не проверялась независимо. Источники местами расходятся (например, мощность 650 и 720 тыс. т в год), все версии указаны на странице. Внутренние режимы варки и отбелки, размеры щепы и скорости машин комбинат не раскрывает: в таких местах значения даны как типовые для отрасли и помечены как «Отрасль». Размеры щепы приведены по ГОСТ 15815-83, это не данные комбината.
